Datenschutzerklärung

LuckyPunch · Stand: 13. November 2026

Wer die App nutzt

LuckyPunch ist eine private Software, die ausschließlich ihr Eigentümer für sich selbst nutzt. Sie wird Dritten nicht angeboten. Daten anderer Personen werden nicht gezielt verarbeitet.

Zugriff auf Google-Daten

Nach Zustimmung des Eigentümers greift LuckyPunch mit der Berechtigung gmail.modify auf dessen eigenes, nur für Gewinnspiele genutztes Gmail-Postfach zu. Die App

  • liest eingehende E-Mails, um sie einzuordnen (z. B. Bestätigung, Gewinn, Newsletter),
  • setzt Labels und verschiebt Newsletter in den Papierkorb (30 Tage wiederherstellbar),
  • sendet keine E-Mails und löscht keine E-Mails endgültig.

Wo die Daten verarbeitet werden

Die Verarbeitung findet auf einem Rechner des Eigentümers statt. Das Zugangstoken für Gmail wird dort verschlüsselt gespeichert. Zur Einordnung einzelner E-Mails wird deren Text an die Claude API von Anthropic übermittelt. Darüber hinaus werden keine Daten an Dritte weitergegeben, verkauft oder für Werbung verwendet.

Nutzung von Daten aus Google-APIs

Daten aus Google-APIs werden nur verwendet, um dem Eigentümer die beschriebenen Funktionen bereitzustellen. Sie werden nicht für Werbung genutzt, nicht verkauft und nicht zum Training von KI-Modellen verwendet. Die Nutzung richtet sich nach der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Speicherdauer und Widerruf

Daten bleiben gespeichert, bis der Eigentümer sie löscht. Der Zugriff auf das Gmail-Konto lässt sich jederzeit unter myaccount.google.com/permissions widerrufen.
